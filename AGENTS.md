# AGENTS.md

> Instructions for AI agents contributing to this repository.

## What this repo is

A curated list of Vision-Language-Action (VLA) models for robotics and embodied AI: foundation models, architectures, benchmarks, and datasets, focused on 2025–2026. The primary artifact is `README.md`.

## Conventions

- All content in `README.md` is in English.
- Each entry follows: `- [Title](URL) — 1–2 sentence note (year).`
- Notes are opinionated: explain *why* it matters, not just what it is.
- Prioritize 2025–2026 work, especially 2026; include older work only when foundational.
- Every entry must have a working URL (prefer arXiv `abs` links and official GitHub repos).
- Organize sections by sub-problem / model class, not by vendor.
- Do not add an entry without a note. No section should exceed ~12 entries without good reason.

## Verification before any commit

- [ ] All URLs resolve.
- [ ] Every entry has a 1–2 sentence note and a year.
- [ ] README renders correctly as Markdown.
