# Contributing

## Criteria

A resource belongs in this list if it:

1. **Is genuinely about Awesome Vision-Language-Action** — not tangentially related.
2. **Is worth someone's time** — include a 1–2 sentence note explaining *why* it matters, not just what it is.
3. **Is recent or seminal** — we prioritize 2025–2026 work; older entries are included only when foundational.

## What doesn't belong

- Off-topic papers or products with no substantive connection to the topic.
- Marketing/announcement posts without technical substance.
- Dead links or unmaintained demos.

## How to contribute

1. Fork and create a branch.
2. Add your resource to the appropriate section in `README.md`.
3. Format: `- [Title](URL) — 1–2 sentence note explaining why it's worth including (year).`
4. Verify the URL resolves, then open a pull request describing what you added and why.
